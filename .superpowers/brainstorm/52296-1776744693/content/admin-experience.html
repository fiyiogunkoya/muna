Workflow: Uploading Photos to a Gallery

1
Create Gallery
Click "Galleries" → "+" button → give it a title
2
Add Photos
Click "Add item" in images array → upload or pick from Unsplash
3
Add Captions
Optional: type a caption for each photo
4
Publish
Click "Publish" → gallery appears on site

Workflow: Changing the Heading Font

1
Open Site Theme
Click "Site Theme" in sidebar
2
Pick a Font
Select from dropdown of 5 curated options
3
Publish
Click "Publish" → all headings update site-wide

Admin Safeguards

Draft → Publish workflow
Changes are drafts until explicitly published. Admins can preview before going live.
Visual editing preview
Presentation Tool lets admins see changes on the actual site before publishing.
Required fields & validation
Titles, slugs, and key fields are required. Can't publish an incomplete gallery.
AI-assisted alt text
Sanity AI Assist (already installed) can auto-generate image descriptions.
