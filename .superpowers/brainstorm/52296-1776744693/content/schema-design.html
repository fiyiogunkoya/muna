Sanity Schema Design

New document types and modifications to support galleries, fonts, and foundation pages

New: Gallery Document

gallery (document type)
title — string (required)
slug — slug (auto-generated from title)
description — text (optional, short summary)
coverImage — image (used as thumbnail on gallery listing)
images — array of image objects, each with:
• image — image with hotspot
• caption — string (optional)
• alt — string (for accessibility, AI-assisted)
date — date (when the event/photos were taken)
orderRank — string (for drag-and-drop ordering in Studio)

New: Site Theme Singleton

siteTheme (singleton — one instance, always accessible)
headingFont — string (dropdown selector)
Options: 5 curated Google Fonts suited for bold/impactful headings
e.g., "Playfair Display", "Oswald", "Bebas Neue", "Montserrat", "Libre Baskerville"
previewText — read-only preview showing the selected font on sample text

Admins pick a heading font from the dropdown → the frontend loads it from Google Fonts → all headings update site-wide. Body font stays fixed (e.g., Inter) for readability.

Extend: Site Settings (existing)

settings (add new fields)
foundationName — string
tagline — string (mission one-liner for hero sections)
contactEmail — string
socialLinks — array of { platform, url }
donateUrl — url (link to GoFundMe, PayPal, etc.)
donateButtonText — string (e.g., "Support Our Mission")

Existing schemas — no changes needed

The existing page, post, and person schemas already support the blog/stories functionality. Posts already have cover images, authors, and rich content with inline images. The page builder with CTA and info sections covers the About and other content pages.
